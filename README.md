# 📊 HR Attrition Analysis Dashboard

## 📌 Project Summary
This project analyzes employee attrition data to understand the factors associated with employees leaving an organization. The data was cleaned and analyzed using **Excel**, with **Pivot Tables and Charts** used to identify key attrition trends and patterns.

## 🎯 Objective
To analyze employee attrition and identify patterns across different employee demographics and job-related factors.

## 🛠️ Tools & Techniques
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Interactive Filters

## 🔍 Key Analysis
- 📈 Employee attrition and attrition rate
- 👥 Attrition by gender, department, education, age group, and job role
- 📊 Employee demographics and workforce trends
- 🎯 Interactive filters for detailed analysis

## 💡 Business Value
The analysis helps HR teams understand attrition patterns and identify areas where employee retention strategies can be considered.
